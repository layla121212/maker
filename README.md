# 오늘의 할 일

매일 할 일을 적고 체크할 수 있는 간단한 앱이에요. 태블릿에서 쓰기 편하도록 글씨와 버튼을 크게 만들었어요.

- 할 일 추가 / 완료 체크 / 삭제
- ◀ ▶ 버튼으로 다른 날짜의 할 일 보기
- 인터넷이 없어도 열리는 PWA (홈 화면에 앱처럼 설치 가능)
- 할 일은 사용하는 기기의 브라우저 안에 저장돼요 (기기끼리 자동으로 공유되지는 않아요)

## 파일 설명

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 화면 뼈대 |
| `style.css` | 색깔, 글씨 크기 등 꾸미기 |
| `app.js` | 추가·체크·삭제 같은 동작 |
| `manifest.json` | 앱 이름, 아이콘 (PWA 설정) |
| `sw.js` | 오프라인에서도 열리게 해주는 파일 |
| `icons/` | 앱 아이콘 |

## GitHub Pages로 배포하기

1. 이 코드를 `main` 브랜치에 합치기
2. GitHub 저장소 → **Settings** → **Pages**
3. **Source**: `Deploy from a branch`, **Branch**: `main` / `/ (root)` 선택 후 **Save**
4. 1~2분 뒤 `https://<내 아이디>.github.io/maker/` 주소로 접속
